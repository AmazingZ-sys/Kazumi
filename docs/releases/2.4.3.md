# Kazumi 2.4.3

同步上游 Kazumi 2.4.2 及其后续更新（截至 `1f79f2d1`），保留本 fork 的剧集搜索、欧乐影院、影视仓 / TVBox 配置和独立更新渠道。

- 新增番剧深链接，可从外部链接打开番剧详情与搜索。Windows EXE 安装程序为当前用户注册 `kazumi://` 协议，卸载时移除；ZIP 便携包仅解压不会自动注册该协议。
- 播放进度条支持悬停和拖动时预览时间，跳转操作按顺序处理。
- 规则仓库支持选择镜像，与番剧请求共用 ECH 网络传输；保留缺少镜像凭据或镜像返回 401 时的官方接口回退。
- 优化收藏分类切换的性能与选中状态。
- 修复排队剧集下载完成后的弹幕缓存，以及退出应用时的托盘图标清理。
- 修复 DLNA 设备筛选和投屏标题信息。
- 更新 Flutter 至 3.47.9，并同步相关依赖。

已有番剧规则、影视来源、影视仓配置及首次引导设置会保留。安装包继续使用本 fork 的固定签名身份和发布渠道。
