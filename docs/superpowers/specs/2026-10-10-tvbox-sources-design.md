# 影视仓 / TVBox 配置与持久化

用户已同意配置导入适配方案，并要求可持久化、添加、修改和删除。

- 在规则管理和剧集搜索提供「影视仓配置」入口。配置列表允许新增、编辑名称及 URL/JSON、刷新、删除；页面沿用现有 Material 样式。
- 支持 HTTP(S) URL、含 sites 的 JSON、单个站点及站点数组。兼容标准 XML 采集接口 0、JSON 采集接口 1/2、远程 HTTP 接口 4；跳过 Spider 3 和不支持的结构并显示原因。URL 返回 HTML 时明确提示地址不是配置。
- 导入的来源转换为 Plugin，type=tv，沿用现有搜索、选集、播放、历史流程。XML 与远程播放通过隔离的 TVBox 适配层处理，请求头及站点参数随规则保存。
- 配置保存 id、名称、原始输入、上次成功导入 JSON、更新时间。生成规则保存配置 id 和站点 key；名称冲突不得替换无关规则。
- 配置与规则在同一个 plugins.json 快照中原子写入，兼容读取旧 JSON 数组；无配置时继续写旧格式。保存失败还原内存；远程加载/解析失败不修改现有配置和来源。启动仅恢复本地快照，不依赖远程网络。
- 配置刷新替换该配置的来源，保留本地删除标记和修改过的规则；编辑原始配置用于调整站点，规则管理用于单独调整来源。删除配置仅删除属于它的规则。
- 不硬编码未验证的第三方源，不加载 JAR/JS/Python；多仓、加密配置和自定义解析运行时明确标记不支持。
- 测试覆盖格式映射、HTTP 参数、XML、远程播放、重启恢复、增改删、刷新回滚、同名隔离与 UI 操作。在线第三方源未给出，不能宣称真实站点可播。
